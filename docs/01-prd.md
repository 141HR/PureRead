# PureRead（净读）产品需求规格说明书（PRD v1.0）

> **文档状态**：Approved（v1.0 定稿）  
> **开源协议**：GPL-3.0  
> **目标平台**：Windows + Android  
> **核心理念**：以自研分页排版与高刷翻页为核心护城河，以统一 `BookProvider` 驱动本地 TXT / EPUB 与在线书源追更，专注纯本地极致单机阅读与安全备份体验。

---

## 1. 目标用户与核心使用场景

| 场景 | 典型环境 | 核心诉求 |
| :--- | :--- | :--- |
| **场景 A：Windows 桌面沉浸/摸鱼阅读** | 办公或居家宽屏显示器，键鼠操作 | 宽屏双栏仿真书页或居中限制行宽，避免文字通栏过长累眼；窗口随时拖拽缩放不丢定位；快捷键翻页、呼出目录、全屏/老板键一键隐藏。 |
| **场景 B：Android 移动端单手/夜间阅读** | 通勤地铁、睡前关灯单手握持 | 覆盖/平移/仿真/滚动顺滑翻页；自定义九宫格点击热区与音量键翻页；护眼纸质背景与 OLED 纯黑主题；无网络时读取预缓存章节。 |
| **场景 C：本地 TXT / EPUB 精品离线阅读与备份迁移** | 换机、重装系统或手动在两台设备间导入配置 | 一键导出 `.pureread.zip` 本地整库备份包并在另一台设备或重装后完整恢复书架、进度（精准到 `charOffset`）、书源与主题配置（`v1.0` 不依赖云端自动同步）。 |
| **场景 D：海量本地大 TXT 与在线追更** | 本地几十 MB 完本小说 + 每日连载追更 | 30MB+ 本地 TXT 秒开不卡顿；在线多源搜索比对、自动追更提醒、一键换源及广告水印净化。 |

## 2. 功能需求清单（FR）

优先级遵循 **MoSCoW**（`Must` / `Should` / `Could` / `Won't`），并映射到三个工程里程碑：**M1 (`v0.1`)**、**M2 (`v0.2`)**、**M3 (`v0.3`)**。

### F1：书架与书籍管理

| 需求项 | 描述 | 优先级 | 里程碑 | 验收标准（AC） |
| :--- | :--- | :---: | :---: | :--- |
| **F1.1 本地 TXT 导入** | 支持单文件/批量选取导入，自动探测 UTF-8 / GB18030 / UTF-16 编码并生成章节目录 | `Must` | `v0.1` | 导入 30MB TXT 不崩溃、无中文乱码，异常无章回标识文本自动按固定字数兜底分段 |
| **F1.2 书架基础视图与排序** | 书架支持列表/封面网格切换，按“最近阅读 / 更新时间 / 书名”排序及置顶 | `Must` | `v0.1` | 书架展示书名、作者、当前读至章节与未读角标；重启应用后排序与置顶状态保留 |
| **F1.3 书籍分组与管理** | 自定义分组（如追更中、完本、本地），支持移除书籍（可选同时清理缓存） | `Should` | `v0.2` | 批量移动分组或删除书籍后列表立即刷新，缓存清理释放对应磁盘空间 |
| **F1.4 在线书籍入架与更新检查** | 详情页一键加入书架；手动下拉刷新或启动时检查连载新章节并高亮提示 | `Must` | `v0.2` | 下拉刷新并发可控、不阻塞 UI；发现新章后角标准确显示新增未读章数 |
| **F1.5 本地 EPUB 导入与解析** | 解析标准 EPUB 2/3 容器、OPF 元数据与封面、NCX/NAV 目录树及 XHTML 文本段落 | `Should` | `v0.3` | 常见文字类 EPUB 可正确识别书名/作者/封面/目录并进入同一套排版引擎阅读，异常畸形 EPUB 给出明确错误提示不崩溃 |

### F2：极致阅读排版与翻页引擎（核心）

| 需求项 | 描述 | 优先级 | 里程碑 | 验收标准（AC） |
| :--- | :--- | :---: | :---: | :--- |
| **F2.1 基于 `charOffset` 的精准锚点** | 进度保存 `chapterIndex + charOffset`，而非脆弱的固定页码 | `Must` | `v0.1` | 调节字号、行距、切换字体、缩放 Windows 窗口后，当前页首句与调整前保持一致，零丢字、零重字 |
| **F2.2 后台预排版与页缓存** | 使用后台 Isolate 预计算当前章及相邻章分页结果，渲染层直接绘制缓存页 | `Must` | `v0.1` | 连续翻页无白屏闪烁；章节末尾顺滑过渡到下一章开头 |
| **F2.3 考究中文排版引擎** | 支持两端对齐、行尾标点避头尾（禁则）、中英文/数字混排微间距、段首双字缩进 | `Must` | `v0.1` | 全角标点（如 `，。！？、》」`）不出现在行首；左标点（如 `《「（`）不孤立留在行尾 |
| **F2.4 排版参数精细调节** | 独立调节字号、字重、行距、段距、上下左右页边距、章节标题样式 | `Must` | `v0.1` | 参数微调可实时或近实时预览生效，支持保存多套排版预设方案 |
| **F2.5 自定义字体与阅读主题** | 支持导入本地 `.ttf / .otf` 字体；内置米白护眼、羊皮纸纹、暗灰、OLED 纯黑等主题并可自配颜色 | `Must` | `v0.1` | 双端均能加载本地自定义字体文件；切换深浅主题后状态栏与弹窗风格同步协调 |
| **F2.6 目录抽屉与跳转撤回** | 章节目录支持正倒序切换、定位当前章、关键字搜章；误触进度条跳转可一键撤回 | `Must` | `v0.1` | 万章级目录列表滚动流畅；拖动底部进度条或点击目录跳转后，提供“回到跳转前位置”按钮 |

### F3：Windows 与 Android 差异化交互

| 需求项 | 描述 | 优先级 | 里程碑 | 验收标准（AC） |
| :--- | :--- | :---: | :---: | :--- |
| **F3.1 Windows 大屏双栏与行宽控制** | 宽屏下支持“双栏仿真书页”与“单栏居中最大行宽限制”切换，窗口拖拽动态重排 | `Must` | `v0.1` | 窗口宽度跨过阈值或切换单/双栏时自动重排并保持原句锚点；大屏单栏不出现超宽通栏 |
| **F3.2 Windows 键鼠与沉浸交互** | 方向键/`Space`/`PgUp`/`PgDn`/鼠标滚轮翻页；`F11` 全屏、快捷键呼出目录、老板键快速隐藏窗口 | `Must` | `v0.1` | 鼠标点击左右边缘及滚轮均可翻页；老板键触发后窗口立即最小化或隐藏且无残留声音 |
| **F3.3 Android 触控翻页模式** | 支持无动画切换、左右平移、覆盖翻页、上下连续滚动（`v0.1`）及仿真卷页动效（`v0.3`） | `Must` / `Could` | `v0.1` / `v0.3` | 覆盖与平移翻页手势跟手且可中途取消回弹；支持左/右半屏点击与九宫格热区自定义 |
| **F3.4 Android 硬件与系统适配** | 支持音量键翻页、屏幕常亮开关、全面屏刘海/挖孔安全区边距与导航栏沉浸隐藏 | `Should` | `v0.1` | 开启音量键翻页后在阅读页拦截音量键事件不弹窗；退出阅读页恢复系统默认行为 |

### F4：书源管理与在线追更

| 需求项 | 描述 | 优先级 | 里程碑 | 验收标准（AC） |
| :--- | :--- | :---: | :---: | :--- |
| **F4.1 书源导入、管理与调试面板** | 支持导入/导出 JS 插件源与 Legado JSON 源，支持分组、启停、权重排序及可视化调试日志 | `Must` | `v0.2` | 调试面板清晰输出每步 HTTP 状态、耗时、命中字段预览、净化前后文本及错误栈 |
| **F4.2 多源聚合搜索与一键换源** | 并发跨多个启用书源搜书并按书名+作者聚合；阅读中支持一键对比其他源最新章并切换 | `Must` | `v0.2` | 换源时按章节标题相似度匹配最接近章节，若未精确命中则给出明确章节选择列表 |
| **F4.3 静默预加载与域名限流** | 读第 N 章时自动静默缓存 N+1 ~ N+3 章；支持整本/指定章数离线缓存；按域名独立限流与 Cookie 管理 | `Must` | `v0.2` | 同一域名并发与 QPS 受限（防止被封 IP）；预加载失败静默记录，不弹出打断阅读的提示框 |
| **F4.4 统一正文净化管道（ContentSanitizer）** | 支持全局及单书/单源正则替换规则，去除防盗水印、乱码与多余空行 | `Must` | `v0.2` | 净化规则同时作用于本地 TXT 与在线书源；原始正文章节可保留或按需重新净化，不破坏原数据 |

### F5：本地备份与数据安全

| 需求项 | 描述 | 优先级 | 里程碑 | 验收标准（AC） |
| :--- | :--- | :---: | :---: | :--- |
| **F5.1 本地整库备份与恢复** | 一键导出/导入 `.pureread.zip` 备份包（书架、进度、书签、书源、净化规则、主题与字体配置） | `Must` | `v0.2` | 在新安装设备上导入备份包后，书架结构、阅读进度与个人配置完整恢复；导入前自动校验包格式与版本号 |
| **F5.2 升级前数据库自动备份** | 检测到 SQLite Schema 版本升级时自动备份旧库文件后再执行迁移 | `Must` | `v0.2` | 模拟旧版本数据库升级失败时可回滚恢复原始备份文件，确保永不损坏书架与阅读进度 |
| **F5.3 双端自动同步（远期规划）** | 基于 `updatedAt` + `deviceId` 的 WebDAV 增量同步或局域网直连快传 | `Won't (v1.0)` | `v1.0+` | `v1.0` 暂不实现；数据库表设计阶段仍预留 `charOffset`、`updatedAt`、`deviceId` 等必要字段以支持后续平滑扩展 |

## 3. 非功能需求（NFR 量化指标）

“极致阅读体验”必须转化为可测试、可验收的工程硬指标：

| 类别 | 指标名称 | 量化目标 | 测试方法 |
| :--- | :--- | :--- | :--- |
| **性能** | 30MB TXT 首次导入建索引耗时 | `< 2.0s`（桌面与主流 Android 中端机） | 30MB 标准测试语料计时（含编码识别与 SQLite 批量写入） |
| **性能** | 已索引书籍二次开书耗时 | `< 200ms`（进入阅读器到首屏渲染完成） | 冷启动打开书架首本大 TXT 计时 |
| **性能** | 章节切换 / 参数调整重排耗时 | `< 50ms`（常规万字以内章节） | 单章排版计算计时与页面缓存命中率统计 |
| **流畅度** | 翻页动画帧率 | `≥ 60fps`（120Hz 屏幕下尽量跑满高刷，无明显掉帧卡顿） | Flutter DevTools Performance Overlay / Raster 帧耗时分析 |
| **准确性** | 分页字数守恒与锚点精度 | 100% 字数守恒（零丢字、零重字）；重排后锚点偏移误差 0 字 | 自动化单测对整章切分后字符串拼接还原校验 |
| **稳定性** | 书源异常隔离能力 | 单个书源超时、死循环 JS、畸形 HTML 100% 捕获并隔离，主进程崩溃率为 0 | 注入恶意超时脚本、空文档、乱码响应进行压测 |
| **可靠性** | 进度持久化与升级防丢 | 翻页防抖落盘（≤ 500ms）+ 退后台/关闭窗口立即落盘；DB 迁移前自动备份 | 强杀进程重启对比阅读位置；模拟旧版 DB 升级回归 |
| **隐私安全** | 数据主权与零遥测 | 100% 本地运行，零第三方统计上报；除用户配置的在线书源外不主动联网 | 网络抓包验证纯本地阅读状态下无外部请求 |

## 4. 核心页面信息架构与双端布局对比

UI 视图层采用自适应壳层，共享同一套业务状态控制器，但在手机竖屏与桌面宽屏上采用符合各自操作习惯的布局：

| 核心页面 | Android 手机端（竖屏单手优先） | Windows 桌面端（宽屏键鼠优先） |
| :--- | :--- | :--- |
| **书架首页** | 底部 Tab 导航（书架 / 发现搜索 / 书源与设置）；顶部搜索框与筛选；支持下拉触发更新检查 | 左侧可折叠导航栏（书架 / 搜索 / 书源管理 / 调试日志 / 设置）；右侧自适应多列书架网格与明确“检查更新”按钮 |
| **阅读主页面** | 全屏沉浸；点击中央呼出上下浮动菜单（目录、夜间切换、设置、换源）；九宫格热区翻页；支持音量键 | 支持常规窗口（可调双栏/单栏居中）与无边框沉浸模式；顶部轻量工具条或右键/快捷键菜单；支持鼠标悬停翻页提示与滚轮 |
| **搜索与书籍详情页** | 全屏搜索输入 → 聚合列表 → 底部/全屏详情页选源入架或试读 | 左侧搜索结果聚合列表 + 右侧实时预览详情/章节目录的双栏分屏视图（无需反复页面跳转） |
| **书源与净化调试页** | 列表管理 + 独立调试页（分段 Tab 查看请求/HTML/提取结果） | **左右双栏工作台**：左侧规则编辑与参数配置，右侧实时输出请求流水、耗时、提取 JSON 与错误信息 |
